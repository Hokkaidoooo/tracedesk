# 来源与贡献范围

TraceDesk 是重新设计和实现的个人客服 Agent 项目。早期学习材料名为 AssistGen，它用于理解客服应用的问题范围；本仓库没有复制该学习包的源码、Vue 编译产物、README、教材、日志、上传资料或配置。

学习包的 README 有 MIT 字样，但主项目完整版权主体和上游地址未核实，因此没有将其作为可直接重新署名发布的代码基础。包内第三方组件的许可证也不被扩展解释为整个学习包的许可。

本仓库新增内容包括：工具注册与执行约束、模型协议适配、回答组装、中文检索与消融、版本化政策、SQLite 会话及申请事务、TypeScript 界面、测试、评测数据与文档。示例商店、客户、订单和政策均为自行构造，不能解释为真实经营数据或线上业绩。
