# 客服工作台

TraceDesk 的界面围绕一次实际咨询组织：左侧选择演示客户与会话，中间查看答复和订单，右侧核对引用与执行记录。售后申请先展示订单、金额和原因，经用户确认后显示服务返回的回执。

## 本地开发

在仓库根目录启动后端后，运行：

```powershell
Set-Location .\web
npm ci
npm run dev
```

开发页面为 `http://127.0.0.1:5173`；`/api` 请求代理到 `http://127.0.0.1:8765`。前端使用 Vite、TypeScript 和原生 DOM，不依赖外部字体、图片服务、CDN 或运行时前端框架。

```powershell
npm run typecheck
npm run build
npm audit --registry=https://registry.npmjs.org
```

构建生成 `src\tracedesk\web\index.html` 及带内容哈希的 JS/CSS 资源，由后端提供静态服务。该目录只放构建产物，修改入口在 `web\`；构建会重新生成此目录。

## 模块与接口

| 文件 | 职责 |
| --- | --- |
| `web\src\api.ts` | 请求、Bearer 身份、接口响应解析和结构化错误 |
| `web\src\main.ts` | 会话、草稿、请求状态和页面事件 |
| `web\src\components.ts` | 对话、引用、执行事件、申请与评测报告的安全 DOM 渲染 |
| `web\src\dom.ts` | DOM 元素、金额与时间格式化 |
| `web\src\style.css` | 布局、状态、键盘焦点与响应式样式 |

HTTP 字段与状态以 [接口契约](api-contract.md) 为准。界面不重复实现退款资格、客户归属、政策生效窗口或订单金额校验；业务裁决由服务返回。

## 交互约定

- **模式真实可见。** 顶部显示服务器返回的提取式或模型模式，每条答复显示该次实际运行模式；不展示模拟流式输出或模型思维链。
- **引用可核对。** 每条引用均可展开，展示原文、来源编号、版本、生效日期与检索分值；分值不表示回答正确率。
- **执行记录来自服务。** 事件按返回顺序展示阶段、状态、详情和耗时，界面不生成占位执行记录。
- **申请必须确认。** 确认前展示金额、订单、原因和有效期；处理中禁用操作按钮。提交成功后只使用真实回执；取消、过期与服务错误明确展示。演示申请不会产生真实退款。
- **失败保留输入。** 发送失败后保留草稿和请求 UUID；原文重试沿用同一个 UUID，修改问题后生成新请求。确认申请的重试同样沿用原请求 UUID。
- **会话只保留在当前页面。** 会话 token 与确认凭证只放内存，不进入 URL、浏览器持久存储、页面文本或日志。刷新后创建新会话；新建会话和切换客户均不重置订单数据库。
- **评测不补造结果。** 报告由 `/api/evaluation` 读取，展示实际生成时间、数据集摘要、检索指标与工作流用例。没有报告时明确显示暂无报告。固定合成回归结果不代表线上模型准确率。

服务和用户提供的文本通过 `textContent` 渲染，不解析为 HTML。请求失败不会自动改用离线回答。参数或响应不符合契约时显示具体错误码和信息。

## 键盘与小屏

消息框支持 Enter 发送、Shift + Enter 换行，并识别输入法组合输入。表单有明确标签，按钮提供焦点提示；回复与操作结果通过 `aria-live` 通知，申请操作结束后焦点回到申请卡片。引用使用原生 `details`，详情页签支持左右方向键和 Home/End。

宽屏同时显示三个区域；1090 px 以下通过分区按钮切换对话与证据，700 px 以下增加会话分区并将导航置顶。最小目标宽度为 320 px。评测表格在自身容器内滚动。减少动态效果偏好通过 `prefers-reduced-motion` 生效。

## 验证入口

类型检查与构建命令覆盖所有 TypeScript 模块。依赖审计应使用支持安全审计端点的 registry；官方 registry 可用上述命令直接指定，无须改全局 npm 配置。

后端就绪后，界面验收覆盖以下真实操作：创建会话、查阅退货政策、读取本人订单、拒绝越权订单访问、准备申请、取消、确认并核对回执、重试失败请求、切换会话和查看评测报告。同步检查 1440 px、768 px、320 px 下的分区、长文本和横向溢出。运行前端开发服务本身不代表这些操作已通过。
