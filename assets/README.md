# 界面截图

图片来自 2026 年 10 月 17 日的 v0.2 生产界面，浏览器连接实际 FastAPI 后端，使用仓库随附的合成演示数据。资料库截图使用真实 BGE ONNX 嵌入和本地关系图；售后截图使用实际会话与确认事务。截图中的成功操作没有使用静态响应替代后端。

| 文件 | 场景 | 尺寸 |
| --- | --- | --- |
| `workspace.png` | 查询订单后准备退款申请，展开实际使用的政策依据 | 1440 × 1000 |
| `refund-receipt.png` | 用户确认后显示数据库返回的申请回执 | 1440 × 1000 |
| `mobile.png` | 手机宽度下的政策对话与输入框 | 390 × 844 |
| `evaluation.png` | 读取随包的实际固定回归报告 | 1440 × 1000 |
| `knowledge-library.png` | 四份资料发布后，实际混合检索并展开原文与原件摘要 | 1440 × 1500 |
| `knowledge-graph.png` | 本地关系图返回有来源的产品兼容路径 | 1440 × 1500 |
| `knowledge-mobile.png` | 手机宽度下的关系路径、原文与下载入口 | 390 × 844 |

界面中的客户、订单、政策和产品均为合成演示资料。运行时间、会话 ID、快照 ID 和申请回执 ID 来自该次实际运行，复跑时会改变。截图没有调用聊天模型；MinerU、Neo4j 与其他能力的实际验证范围见 [v0.2 验证记录](../docs/validation-v0.2.md)。
